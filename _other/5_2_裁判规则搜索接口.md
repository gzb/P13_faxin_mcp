# 裁判规则搜索接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

**裁判规则搜索接口**

### 1.2 接口地址

```
POST https://m-v2.faxin.cn/m/v6/api/alyz/searchdata
```

### 1.3 功能描述

该接口用于查询法信平台中的**裁判规则数据**。

接口根据案件关键词、全文内容、罪名分类、审理程序、法院、案件来源等条件进行检索，返回符合条件的裁判规则列表。

主要应用场景：

- 裁判规则检索
- 类案检索
- 法律人工智能辅助分析
- 案例知识库建设
- MCP法律检索服务

支持能力：

- 标题检索
- 裁判规则全文检索
- 案由/罪名分类筛选
- 审理程序筛选
- 法院筛选
- 案件来源筛选
- 分页查询

# 4. 请求参数详细说明

## 4.1 分页参数

| 参数     | 示例 | 说明            |
| -------- | ---- | --------------- |
| pagesize | 10   | 每页返回数量    |
| pagenum  | 1    | 当前页，从1开始 |

示例：

```
{
    "pagesize":10,
    "pagenum":1
}
```

表示：

> 查询第一页，每页10条裁判规则。

------

## 4.2 搜索参数

### keytitle

标题搜索。

示例：

```
{
    "keytitle":"抢劫罪"
}
```

匹配：

```
以暴力、胁迫的方法将被害人控制...
构成抢劫罪
```

------

### keycontent

全文检索。

示例：

```
{
    "keycontent":"全文"
}
```

用于指定全文搜索范围。

------

## 4.3 案由分类

### sort_id

案件分类编码。

示例：

```
{
    "sort_id":"001"
}
```

返回：

```
[
 {
   "value":"抢劫罪",
   "key":"0010501"
 }
]
```

------

## 4.4 审理程序

### slcx_id

审理程序。

返回示例：

```
[
 {
   "value":"二审",
   "key":"02"
 }
]
```

编码：

| key  | 说明     |
| ---- | -------- |
| 01   | 一审     |
| 02   | 二审     |
| 其他 | 其他审级 |

------

## 4.5 排序规则

参数：

```
sort
```

示例：

```
{
 "sort":"-sort_num,-zs_date,-tj_date"
}
```

含义：

按照：

1. 推荐排序
2. 裁判日期
3. 发布时间

倒序排列。

```
              用户输入查询条件

                     |
                     ↓

        裁判规则搜索接口
        /alyz/searchdata

                     |
                     ↓

          返回裁判规则列表

                     |
```

# 13. 开发注意事项

## 13.1 gid用途

字段：

```
gid
```

例如：

```
C1483618
```

作用：

- 查询案例全文
- 建立案例实体
- 构建案例知识图谱

------

## 13.2 pagehtml字段

接口返回：

```
pagehtml
```

该字段为网页分页HTML。

非Web应用建议忽略。

推荐自行计算：

```
总页数 = total / pagesize
```

------

## 13.3 HTML标签处理

以下字段可能包含HTML：

- alyz_title
- fypl
- keywordpath

例如：

```
<font color='red'>抢劫罪</font>
```

非浏览器环境需要：

- HTML转义
- 标签过滤

## 14.3 法律知识图谱

可建立：

```
裁判规则
    |
    |--关联--> 案例
    |
    |--关联--> 法院
    |
    |--关联--> 罪名
    |
    |--关联--> 法律条文
```

------

该接口可作为**法信裁判规则数据入口接口**，结合案例详情接口、法规关联接口，可形成面向AI法律应用的案例知识服务能力。
