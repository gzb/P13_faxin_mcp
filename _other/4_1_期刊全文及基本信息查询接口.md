# 期刊全文及基本信息查询接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

**期刊文章详情查询接口**

------

### 1.2 接口地址

```
POST https://m-v2.faxin.cn/m/v6/api/jrflqk/content
```

------

### 1.3 功能说明

根据期刊文章唯一标识 `gid`，查询期刊文章详细信息。

接口返回：

- 期刊文章基本信息；
- 文章标题；
- 作者信息；
- 来源期刊；
- 年份、期号；
- 分类信息；
- 文章摘要；
- 正文全文；
- PDF文件地址。

主要用于：

- 期刊详情展示；
- 法学文献检索；
- 法律知识库建设；
- AI法律知识增强；
- 文献关联分析；
- MCP期刊查询服务。

------

# 11. 正文全文字段

## 字段

```
fulltext
```

类型：

String

------

## 示例

```
<div class="qk_bt">
刑事法的欧洲一体化及其挑战
</div>

<div class="qk_zz">
［德］赫尔穆特·查致格 著 程捷 译
</div>
```

------

## 内容特点

全文包含：

### 1. HTML标签

例如：

```
<div>
<br>
<span>
```

需要解析处理。

------

### 2. 法规关联链接

正文中可能存在：

```
<a 
fid="A192308"
tiao="0"
class="flink">
刑法
</a>
```

说明：

文章引用法规：

```
fid=A192308
```

对应：

法规文件ID。

可以进一步关联：

```
期刊文章
    |
    |引用
    ↓
法规文件
    |
    ↓
具体条款
```

适合构建：

法律知识图谱。

------

### 3. 文献引用标记

例如：

```
<a href="#s_1">
[1]
</a>
```

表示参考文献引用。

# 15. 开发处理建议

## 15.1 HTML正文处理

建议保存两个字段：

### 原始正文

```
fulltext_html
```

保存：

- HTML结构；
- 法规链接；
- 引用关系。

### 清洗正文

```
fulltext_text
```

处理：

- 去HTML标签；
- 保留段落；
- 用于全文检索。

# 18. 业务关联关系

该接口可与法规、案例接口形成法律知识网络：

```
                 ┌───────────┐
                 │ 期刊文章   │
                 │ gid       │
                 └─────┬─────┘
                       │
             引用法规/司法解释
                       │
                       ↓
                 ┌───────────┐
                 │ 法规条款   │
                 │ gid+tiao  │
                 └─────┬─────┘
                       │
                  裁判案例
                       │
                       ↓
                 ┌───────────┐
                 │案例全文    │
                 └───────────┘
```

# 接口总结

| 项目     | 说明                       |
| -------- | -------------------------- |
| 接口名称 | 期刊文章详情查询           |
| 请求方式 | POST                       |
| 核心参数 | gid                        |
| 返回内容 | 期刊基本信息+全文+PDF      |
| 正文格式 | HTML                       |
| 数据粒度 | 单篇文章                   |
| 主要用途 | 期刊库、全文检索、AI知识库 |
| 扩展能力 | 法规引用关系抽取、知识图谱 |

该接口属于法信**期刊资源详情服务接口**，可作为法律文献库建设、AI检索增强（RAG）、知识图谱构建的重要数据来源。
