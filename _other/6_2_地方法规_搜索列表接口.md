# 地方法规搜索列表接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

地方法规搜索列表接口

### 1.2 接口地址

```
POST http://m-v2.faxin.cn/m/v6/api/fl/dffl/searchdata
```

### 1.3 功能描述

该接口用于查询法信平台中的**地方法规数据**，根据法规库类型、关键词、效力、时效性、制定机关、日期范围等条件进行检索，返回符合条件的法规文件列表信息。

支持：

- 地方性法规查询
- 地方政府规章查询
- 地方司法文件查询
- 地方规范性文件查询
- 指定地区法规查询
- 高级条件组合检索
- 分页查询

# 4. 法规库类型（libid）

`libid`用于限定查询的数据范围。

| libid值    | 含义                   |
| ---------- | ---------------------- |
| 不传       | 查询全部地方性法规数据 |
| 010201_all | 地方性法规             |
| 010202_all | 地方政府规章           |
| 010203_all | 地方司法文件           |
| 010204_all | 地方规范性文件         |
| 010205_all | 北京市地方文件         |

示例：

查询地方性法规：

```
{
    "libid":"010201_all"
}
```

# 11. 开发注意事项

## 11.1 分页处理

接口采用页码分页：

- `pagesize`：每页数量
- `pagenum`：页码，从1开始

例如：

```
{
 "pagesize":20,
 "pagenum":"3"
}
```

表示：

> 查询第3页，每页20条数据。

------

## 11.2 gid字段用途

返回结果中的：

```
gid
```

为法规文件唯一标识。

后续可用于：

- 获取法规全文
- 查询法规历史版本
- 查询引用关系
- 构建法规知识图谱

------

## 11.3 pagehtml字段说明

`pagehtml`为前端页面分页组件生成代码。

接口调用方如果为：

- APP
- API服务
- MCP服务
- 数据同步程序

通常无需使用该字段，可直接根据：

```
total
pagesize
pagenum
```

自行生成分页。

# 13. 接口应用场景

该接口适用于：

1. 法规检索系统
   - 地方法规全文检索
   - 高级筛选
2. AI法律助手
   - MCP工具封装
   - Agent法规查询能力
3. 法规知识库建设
   - 批量同步法规目录
   - 根据gid抓取全文
4. 法规知识图谱
   - gid作为法规实体节点
   - 建立法规引用、关联关系

------

该接口建议作为“地方法规数据入口接口”，后续结合 **法规详情接口（gid查询全文）**、**法规历史版本接口**、**法规引用关系接口** 可形成完整法规数据服务体系。
