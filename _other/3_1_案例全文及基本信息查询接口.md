# 案例全文及基本信息查询接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

**案例详情信息查询接口（裁判文书）**

### 1.2 接口地址

```
POST https://m-v2.faxin.cn/m/v6/api/statute/info/case/getCaseInfo
```

------

## 1.3 功能说明

根据案例唯一标识 `statuteId` 查询案例的详细信息。

接口返回：

- 案例基本信息；
- 案件名称；
- 案号；
- 审理法院；
- 审理日期；
- 案例全文内容。

主要用于：

- 案例详情页面展示；
- 案例全文检索；
- AI案例分析；
- 类案检索；
- 法律知识库建设；
- MCP案例查询服务。

# 4. 请求Header

## 4.1 必需Header

| Header       | 类型   | 是否必填 | 说明          |
| ------------ | ------ | -------- | ------------- |
| Content-Type | String | 是       | JSON请求      |
| accesstoken  | String | 是       | 用户认证Token |

示例：

```
Content-Type: application/json

accesstoken: xxxxx
```

------

# 5. 请求参数

## 5.1 请求Body

请求格式：

```
{
    "statuteId":"ZebhHAMhaV+FYtZnrqHmyw==",
    "appToken":""
}
```

------

## 5.2 参数说明

| 参数名称  | 类型   | 必填 | 示例                     | 说明       |
| --------- | ------ | ---- | ------------------------ | ---------- |
| statuteId | String | 是   | ZebhHAMhaV+FYtZnrqHmyw== | 案例唯一ID |
| appToken  | String | 否   | ""                       | 应用Token  |

# 7. 返回结果说明

## 7.1 返回结构

```
{
    "code":200,
    "message":"OK",
    "success":true,
    "total":0,
    "data":{}
}
```

------

# 8. 返回字段说明

## 8.1 一级字段

| 字段    | 类型    | 说明           |
| ------- | ------- | -------------- |
| code    | Integer | 接口返回状态码 |
| message | String  | 返回消息       |
| success | Boolean | 是否成功       |
| total   | Integer | 数据总量       |
| data    | Object  | 案例详细数据   |

------

# 9. 案例信息字段说明

`data`对象：

| 字段       | 类型   | 说明         |
| ---------- | ------ | ------------ |
| gid        | String | 案例唯一标识 |
| title      | String | 案例标题     |
| caseNumber | String | 案件编号     |
| courtName  | String | 审理法院     |
| trialData  | String | 审理日期     |
| fullText   | String | 案例全文     |

------

## 9.1 gid

示例：

```
"gid":"ZebhHAMhaV+FYtZnrqHmyw=="
```

说明：

案例数据唯一ID。

用于：

- 案例关联；
- 案例收藏；
- 类案分析。

------

## 9.2 title

案例标题。

示例：

```
"title":"岩甩走私、贩卖、运输、制造毒品一审刑事判决书"
```

------

## 9.3 caseNumber

案件编号。

示例：

```
"caseNumber":"2014西刑初188号"
```

------

## 9.4 courtName

审理法院。

示例：

```
"courtName":
"云南省西双版纳傣族自治州中级人民法院"
```

------

## 9.5 trialData

审理日期。

示例：

```
"trialData":
"2014-06-30 00:00:00"
```

格式：

```
yyyy-MM-dd HH:mm:ss
```

------

## 9.6 fullText

案例全文。

示例：

```
"fullText":
"中华人民共和国<br />
云南省西双版纳傣族自治州中级人民法院<br />
刑事判决书<br />
（2014）西刑初字第188号..."
```

说明：

- 返回HTML格式文本；
- 使用 `<br />` 表示换行；
- 前端展示需要HTML解析；
- 数据入库建议清洗HTML标签。

# 11. 状态判断

成功：

```
{
    "success":true,
    "code":200
}
```

失败：

可能情况：

| 情况          | 说明               |
| ------------- | ------------------ |
| success=false | 请求失败           |
| code非200     | 接口异常           |
| data为空      | 案例不存在或无权限 |

# 14. 数据处理建议

## 14.1 HTML清洗

原文：

```
中华人民共和国<br />
云南省西双版纳傣族自治州中级人民法院<br />
刑事判决书
```

建议转换：

```
中华人民共和国

云南省西双版纳傣族自治州中级人民法院

刑事判决书
```

处理：

- 去除HTML标签；
- 保留段落结构；
- 保存原始全文。
