# 法律关联页面法规信息查询接口技术说明文档

------

# 1. 接口概述

## 1.1 接口名称

法律关联信息查询接口（link/lawinfo）

------

## 1.2 接口地址

```
POST https://m-v2.faxin.cn/m/v6/api/link/lawinfo
```

## 1.3 功能介绍

该接口用于根据指定法规文件的：

- 法规唯一标识 `gid`
- 条款编号 `tiao`

查询对应法律条款的详细信息。

接口返回：

1. 法规文件基础信息
2. 指定条款正文内容
3. 法规分类信息
4. 制定机关信息
5. 法规效力及有效状态信息

主要应用场景：

- 法律关联页面展示
- 案例关联法规展示
- 法律条文引用
- AI法律知识库构建
- 法律条款精准定位

------

# 3. 请求参数

## 3.1 请求Body

示例：

```
{
    "gid":"A192308",
    "tiao":"5"
}
```

------

## 3.2 参数定义

| 参数名 | 类型   | 是否必填 | 说明           |
| ------ | ------ | -------- | -------------- |
| gid    | String | 是       | 法规文件唯一ID |
| tiao   | String | 是       | 条款编号       |

------

# 4. 参数详细说明

## 4.1 gid

### 定义

法规文件唯一标识。

来源：

- 国家法律搜索接口
- 法律正文接口

示例：

```
{
    "gid":"A192308"
}
```

对应：

```
中华人民共和国刑法(1997年修订)
```

------

## 4.2 tiao

### 定义

需要查询的法律条款编号。

示例：

```
{
    "tiao":"5"
}
```

表示查询：

```
中华人民共和国刑法 第五条
```

传参规则：

| 条款           | 参数值 |
| -------------- | ------ |
| 第一条         | 1      |
| 第五条         | 5      |
| 第三百五十一条 | 351    |

注意：

参数传数字，不传中文条号。

正确：

```
{
 "tiao":"351"
}
```

错误：

```
{
 "tiao":"第三百五十一条"
}
```

# 6. data字段说明

返回：

```
{
    "fileinfo":{}
}
```

| 字段     | 类型   | 说明               |
| -------- | ------ | ------------------ |
| fileinfo | Object | 法规文件及条款信息 |

------

# 7. fileinfo字段说明

| 字段名     | 类型   | 说明         |
| ---------- | ------ | ------------ |
| gid        | String | 法规文件ID   |
| title      | String | 法规名称     |
| fulltext   | String | 当前条款正文 |
| fwzh       | String | 发文字号     |
| fdate      | String | 发布日期     |
| ssrq       | String | 施行日期     |
| fdep_id    | Array  | 制定机关     |
| sort_id    | Array  | 主题分类     |
| shixiao_id | Array  | 时效状态     |
| xiaoli_id  | Array  | 效力等级     |

------

# 8. 字段详细说明

## 8.1 gid

示例：

```
"gid":"A192308"
```

说明：

法规文件唯一编号。

------

## 8.2 title

示例：

```
"title":"中华人民共和国刑法(1997年修订)"
```

说明：

法规名称。

------

## 8.3 fulltext（核心字段）

示例：

```
"fulltext":
"第五条 【罪责刑相适应原则】刑罚的轻重，应当与犯罪分子所犯罪行和承担的刑事责任相适应。"
```

说明：

返回指定条款完整正文。

特点：

- 已根据 `gid+tiao` 精确定位
- 返回单条法律内容
- 支持HTML标签

例如：

返回内容可能包含：

```
<br>
<a name="">
```

开发展示时建议进行HTML解析。

------

## 8.4 fdep_id 制定机关

返回：

```
[
    {
        "value":"全国人民代表大会",
        "key":"001"
    }
]
```

字段：

| 字段  | 说明     |
| ----- | -------- |
| key   | 机构编码 |
| value | 机构名称 |

------

## 8.5 fdate 发布日期

示例：

```
"fdate":"1997-03-14 00:00:00"
```

说明：

法规公布日期。

------

## 8.6 fwzh 发文字号

示例：

```
"fwzh":"中华人民共和国主席令第八十三号"
```

说明：

法规发布文号。

------

## 8.7 ssrq 施行日期

示例：

```
"ssrq":"1997-10-01 00:00:00"
```

说明：

法规开始实施日期。

------

## 8.8 sort_id 主题分类

示例：

```
[
 {
   "value":"刑法综合规定与解释",
   "key":"0601"
 }
]
```

说明：

法律主题分类。

------

## 8.9 shixiao_id 时效状态

示例：

```
[
 {
  "value":"已被修改",
  "key":"03"
 }
]
```

说明：

法规当前状态。

常见状态：

| key  | 说明     |
| ---- | -------- |
| 01   | 现行有效 |
| 03   | 已被修改 |

------

## 8.10 xiaoli_id 效力等级

示例：

```
[
 {
   "value":"法律",
   "key":"0201"
 }
]
```

说明：

法规效力层级。

常见：

| key  | value          |
| ---- | -------------- |
| 0201 | 法律           |
| 0502 | 部门规范性文件 |

# 10. 调用流程

```
        法律搜索接口
              |
              |
          获取gid
              |
              ↓
        获取条款编号
              |
              ↓
   /link/lawinfo接口
              |
              ↓
    返回法规+条款信息
              |
      -----------------
      |               |
   法规元数据       条款正文
```

# 12. 开发注意事项

## 12.1 fulltext字段处理

由于正文可能包含：

```
<br>
<a>
```

建议：

- 页面展示：HTML解析后展示
- 数据库存储：保留原始HTML
- AI处理：清洗HTML标签后使用

------

## 12.2 条款不存在处理

如果：

- gid错误
- tiao不存在

可能返回：

```
{
 "data":{}
}
```

业务需要做好空数据判断。

------

## 12.3 与条款查询接口区别

| 接口                   | 用途                 |
| ---------------------- | -------------------- |
| getcommondatabygidtiao | 法规条款查询         |
| link/lawinfo           | 关联页面法规信息查询 |

两者返回内容类似，但：

- `getcommondatabygidtiao` 更偏向法律正文服务
- `link/lawinfo` 更偏向关联场景（案例、链接页面）

------

# 13. 接口定位总结

该接口属于法信法律知识库中的：

**“法规文件 + 指定条款综合信息查询接口”**

数据模型：

```
法规文件(gid)
       |
       |
       +---- 基础信息
       |
       +---- 条款编号(tiao)
                    |
                    |
                 条文正文(fulltext)
```

可作为：

- 法律检索系统
- 案例关联法规
- AI法律助手
- 法律知识图谱

的基础数据接口。
