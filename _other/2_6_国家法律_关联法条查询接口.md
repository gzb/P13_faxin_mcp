# 关联法条查询接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

**法规关联法条查询接口**

### 1.2 接口地址

```
GET https://m-v2.faxin.cn/m/v6/api/fl/zyfl/getlawlinktiao
```

### 1.3 功能说明

根据指定法规文件的 **gid（法规文件ID）** 和 **条款编号（tiao_num）**，查询该条法规被其他法规文件引用形成的**关联法条信息**。

接口返回：

- 当前法规文件的条款信息；
- 引用该条款的其他法规文件信息；
- 引用位置（关联法规的具体条款）；
- 关联法规的基本属性信息。

主要用于：

- 法规详情页展示“关联法条”；
- 法律知识图谱构建；
- 法规引用关系分析；
- MCP服务/智能问答场景中的法规关系查询。

------

# 2. 请求说明

## 2.1 请求方式

```
GET
```

## 2.2 请求地址示例

```
https://m-v2.faxin.cn/m/v6/api/fl/zyfl/getlawlinktiao?gid=A192308&tiao_num=6
```

------

# 3. 请求参数

## 3.1 Query参数

| 参数名称 | 类型   | 必填 | 示例    | 说明                     |
| -------- | ------ | ---- | ------- | ------------------------ |
| gid      | String | 是   | A192308 | 法规文件唯一标识ID       |
| tiao_num | String | 是   | 6       | 法规条款编号（条的序号） |

### 参数说明

例如：

```
gid=A192308
tiao_num=6
```

表示：

查询法规文件：

```
A192308
```

中的：

```
第6条
```

对应的关联引用法条。

------

# 4. 请求Header

接口依赖用户访问Token，需要携带：

| Header      | 是否必填 | 说明              |
| ----------- | -------- | ----------------- |
| accesstoken | 是       | 用户访问认证Token |
| User-Agent  | 否       | 客户端信息        |
| Referer     | 否       | 来源页面          |

示例：

```
accesstoken: xxxxxxx
```

------

# 5. CURL调用示例

```
curl "https://m-v2.faxin.cn/m/v6/api/fl/zyfl/getlawlinktiao?gid=A192308&tiao_num=6" \
-H "Accept: */*" \
```

# 8. 数据列表说明

返回数据：

```
data.datas
```

类型：

```
Array
```

表示关联法条列表。

每个元素表示一条法规引用关系。

# 9. 关联关系字段说明

## 9.1 当前法规条款信息

| 字段         | 类型   | 说明             |
| ------------ | ------ | ---------------- |
| link_id      | String | 关联关系ID       |
| lib          | String | 法规库类型       |
| file_id      | String | 当前法规文件ID   |
| tiao_num     | String | 当前法规条款编号 |
| tiao_content | String | 当前条款内容     |

示例：

```
{

 "tiao_num":"6",
 "tiao_content":
 "<p>第六条 【属地管辖权】...</p>"
}
```

| link_tiao_num | String | 引用法规条款编号       |

# 12. 业务处理流程

```
                请求参数
                   |
                   |
        gid + tiao_num
                   |
                   ↓
        查询法规文件条款
                   |
                   ↓
        查找引用关系表
                   |
                   ↓
     获取引用该条款的法规
                   |
                   ↓
       返回关联法条列表
```

------

# 13. 数据关系模型说明

该接口返回的数据可抽象为法规引用关系：

```
┌──────────────────┐
│ 当前法规文件      │
│ file_id          │
│                  │
│ 第6条             │
└────────┬─────────┘
         │
         │ 被引用
         ↓
┌──────────────────┐
│ 关联法规文件      │
│ link_file_id     │
│                  │
│ 第1条 / 第9条     │
└──────────────────┘
```

可用于构建：

```
法规A 第6条
      |
      |引用关系
      ↓
法规B 第1条
法规C 第9条
法规D 第3条
```

形成法律知识图谱中的：

```
法规 → 条款 → 引用 → 条款
```

关系。

# 14. 开发注意事项

## 14.1 tiao_num格式

当前接口使用字符串类型：

```
"6"
```

建议调用时保持字符串格式。

## 14.2 HTML内容处理

```
tiao_content
```

和

```
link_content
```

字段返回HTML：

例如：

```
<p>
第六条……
</p>
```

前端展示需要：

- HTML解析；
- 或转换为纯文本。

## 14.3 Token有效性

接口依赖：

```
accesstoken
```

Token失效可能返回：

- 空数据；
- 非成功状态；
- 权限错误。

## 14.4 一对多关系

一个法规条款可能对应多个引用关系：

例如：

```
刑法 第6条

    ↓

司法解释A 第1条

司法解释B 第9条

司法解释C 第3条
```

因此：

```
data.datas
```

必须按照列表处理。
