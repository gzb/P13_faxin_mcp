# 法规条款关联裁判规则列表查询接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

法规条款引用裁判规则查询接口

### 1.2 接口地址

```
POST https://m-v2.faxin.cn/m/v6/api/alyz/getalyzlink
```

### 1.3 接口功能

根据指定法规文件的 `gid` 和具体条款 `tiao`，查询**引用该法规条款的裁判规则数据列表**。

该接口用于实现：

- 法规条款关联裁判规则查询
- 法规司法适用案例分析
- 法律知识关联展示
- AI法律问答中的案例推荐
- 法规知识图谱关联分析

业务逻辑：

```
法规文件
   |
   | gid
   |
法规条款
   |
   | tiao
   |
查询引用关系
   |
   |
裁判规则库
   |
   |
返回相关裁判规则列表
```

例如：

输入：

```
{
    "gid":"A192308",
    "tiao":"5"
}
```

表示：

查询法规 `A192308` 第 `5` 条对应的裁判规则。

返回：

```
引用该法规条款的裁判规则列表
```

| 参数名称 | 类型   | 必填 | 示例    | 说明              |

# 16. 开发注意事项

1. **gid必须为法规ID**

例如：

正确：

```
"gid":"A192308"
```

不要传裁判规则gid。

------

1. **tiao为字符串**

正确：

```
"tiao":"5"
```

------

1. **裁判规则数量可能为空**

无关联数据时：

```
{
 "resultitem":[]
}
```

属于正常返回。

------

1. **alyz_content字段可能较长**

建议：

- 数据库字段使用TEXT
- 前端展示支持折叠
- AI处理时作为裁判观点文本使用

# 17. 接口简要描述（接口目录）

| 项目     | 说明                                   |
| -------- | -------------------------------------- |
| 接口名称 | 法规条款引用裁判规则查询               |
| 接口地址 | /m/v6/api/alyz/getalyzlink             |
| 请求方式 | POST                                   |
| 输入参数 | 法规gid、条款号、分页参数              |
| 返回数据 | 裁判规则列表                           |
| 数据类型 | 司法案例知识                           |
| 主要用途 | 法规关联案例、智能法律检索、AI辅助审判 |

------

该接口本质属于**“法规条款 → 裁判规则”知识关联接口**，可用于构建法律知识图谱中的**规范依据与司法实践关联关系**。与前面的“法规 → 期刊”接口组合后，可以形成：

```
法规条款
   |
   +---- 学术解释（期刊）
   |
   +---- 司法适用（裁判规则）
```

为法律检索、AI问答、智能审判辅助提供关联数据
