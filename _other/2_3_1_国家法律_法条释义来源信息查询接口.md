# 法条释义来源信息查询接口技术说明文档

------

# 1. 接口概述

## 1.1 接口名称

法条释义来源信息查询接口

## 1.2 接口地址

```
POST http://m-v2.faxin.cn/m/v6/api/ftsy/getftsyrightlist
```

------

## 1.3 功能介绍

该接口用于获取指定法律条文对应的**法条释义来源列表信息**。

通过法律文章ID（`gid`）和条文编号（`tiao`），查询该条法律对应的：

- 官方释义来源
- 专家学者释义来源
- 出版机构信息
- 释义类型标识

接口返回的数据可作为后续调用**法条释义全文查询接口**的输入参数。

------

# 2. 请求说明

## 2.1 请求方式

| 项           | 内容             |
| ------------ | ---------------- |
| HTTP方法     | POST             |
| Content-Type | application/json |
| 请求参数格式 | JSON             |
| 返回格式     | JSON             |

------

## 2.2 请求示例

```
POST /m/v6/api/ftsy/getftsyrightlist

Content-Type: application/json
```

请求Body：

```
{
    "gid": "A296510",
    "tiao": "1"
}
```

------

# 3. 请求参数说明

## 3.1 输入参数

| 参数名 | 类型   | 必填 | 默认值 | 说明               |
| ------ | ------ | ---- | ------ | ------------------ |
| gid    | String | 是   | 无     | 法律文章唯一标识ID |
| tiao   | String | 是   | 无     | 法律条文编号       |

------

## 3.2 参数说明

### gid

说明：

- 对应法律法规文章ID。
- 通常来源于法律正文接口或法律列表接口。

示例：

```
{
    "gid":"A296510"
}
```

------

### tiao

说明：

- 指定查询第几条法律条文。
- 与法律正文中的具体条款对应。

示例：

```
{
    "tiao":"1"
}
```

------

# 4. 返回参数说明

## 4.1 顶层返回结构

| 字段    | 类型    | 说明             |
| ------- | ------- | ---------------- |
| msg     | String  | 返回消息         |
| code    | String  | 返回状态码       |
| data    | Array   | 法条释义来源列表 |
| success | Boolean | 请求是否成功     |

------

## 4.2 状态码说明

| code | 说明     |
| ---- | -------- |
| 0    | 查询成功 |
| 其他 | 查询失败 |

------

# 5. data返回结构说明

接口返回一个数组，每个元素代表一种法条释义来源。

返回结构：

```
[
    {
        "institution":"",
        "gid":"",
        "tiao":"",
        "author":"",
        "publisher":"",
        "id":"",
        "type":""
    }
]
```

------

## 5.1 字段说明

| 字段名      | 类型   | 说明                             |
| ----------- | ------ | -------------------------------- |
| institution | String | 释义来源机构/类型                |
| gid         | String | 法律文章ID                       |
| tiao        | String | 条文编号                         |
| author      | String | 释义来源名称                     |
| publisher   | String | 出版社或出版机构                 |
| id          | String | 释义记录ID                       |
| type        | String | 释义类型标识（用于全文查询接口） |

# 7. 调用流程

该接口通常作为法条释义查询流程中的第一步。

```
             法律正文
                |
                |
          获取 gid
                |
                ↓
┌─────────────────────┐
│ getftsyrightlist    │
│ 获取释义来源列表      │
└─────────────────────┘
                |
                |
        返回多个释义来源
                |
                ↓
        用户选择释义来源
                |
                |
          获取 type
                |
                ↓
┌─────────────────────┐
│ 后续调用释义全文接口 │
└─────────────────────┘
```

# 9. 开发注意事项

## 9.1 type字段不要自行生成

建议：

- 使用接口返回的 `type` 字段；
- 原值传递给全文查询接口。

原因：

- 不同出版社可能存在同名释义；
- type可能包含特殊格式；
- 自行拼接可能导致查询失败。

------

## 9.2 一个条文可能存在多个释义来源

例如：

```
中华人民共和国刑法 第1条

├── 全国人大法工委释义
│
├── 人民法院出版社释义
│
└── 学者论著释义
```

因此：

`data` 返回结果为数组。

------

## 9.3 数据用途建议

该接口返回的数据适合用于：

- 法律知识库构建
- AI法律问答知识关联
- RAG检索增强
- 法律条文智能解释
- 智能审判辅助

## 接口定位

该接口是法信**“法律条文 → 权威释义来源”**的数据入口接口，用于为后续获取法律条文解释全文提供来源选择和参数支撑。
