# 法规条款关联地方法规列表查询接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

地方法规引用关系查询接口

### 1.2 接口地址

```
POST https://m-v2.faxin.cn/m/v6/api/fl/dffl/getdffllink
```

### 1.3 功能描述

根据指定**法规文件 gid** 和 **法规条款号 tiao**，查询引用该法规条款的**地方法规数据列表**。

应用场景：

- 查询某一法律条文被哪些地方性法规引用；
- 构建法规关联关系；
- 支撑法规知识图谱中的“法规 → 被引用法规”关系分析；
- 展示法规引用链路。

例如：

输入：

```
gid=A192308
tiao=6
```

表示查询：

> 哪些地方性法规引用了《刑法》（gid=A192308）第6条。

返回：

> 引用了该条款的地方法规列表。

## 2.1 请求方式

```
POST
```

## 2.2 Content-Type

```
application/json
```

------

# 3. 请求参数

## 3.1 请求JSON结构

```
{
    "pagenum": 1,
    "pagesize": 10,
    "gid": "A192308",
    "tiao": "6"
}
```

------

## 3.2 参数说明

| 参数名   | 类型    | 必填 | 示例    | 说明                   |
| -------- | ------- | ---- | ------- | ---------------------- |
| gid      | String  | 是   | A192308 | 被引用法规文件唯一标识 |
| tiao     | String  | 是   | 6       | 被引用法规条款号       |
| pagenum  | Integer | 是   | 1       | 当前页码，从1开始      |
| pagesize | Integer | 是   | 10      | 每页返回数量           |

------

# 10. 接口处理逻辑说明

业务逻辑如下：

```
                 输入
                   |
        +----------+----------+
        |                     |
      gid                 tiao
        |                     |
        +----------+----------+
                   |
          法规引用关系检索
                   |
          查询引用关系表
                   |
     筛选引用来源库=地方法规(dffl)
                   |
              分页处理
                   |
              返回列表
```

------

# 11. 与其他法规关联接口关系

该接口属于法信法规关联关系查询接口族：

| 接口             | 用途                         |
| ---------------- | ---------------------------- |
| 国家法律引用查询 | 查询引用某条法律的国家法律   |
| 司法解释引用查询 | 查询引用某条法律的司法解释   |
| 期刊引用查询     | 查询引用某条法律的期刊文章   |
| 地方法规引用查询 | 查询引用某条法律的地方性法规 |

本接口对应：

```
被引用法规
    |
    | gid+tiao
    ↓
引用关系
    ↓
地方法规列表
```

# 12. 开发注意事项

## 12.1 分页处理

建议：

第一次请求：

```
{
 "pagenum":1,
 "pagesize":50
}
```

根据：

```
total
```

判断是否继续请求。

------

## 12.2 gid字段说明

gid为法信内部法规唯一ID，例如：

```
A192308
```

通常：

- A开头：法律法规类数据
- B开头：地方性法规等关联数据

（具体编码规则以法信内部数据字典为准）

------

## 12.3 tiao字段说明

`tiao`表示法规条款号。

例如：

```
第六条
```

传递：

```
"6"
```

注意：

- 不需要传“第”
- 不需要传“条”
- 多条情况下需要按照接口约定处理

------

# 13. 错误返回

可能返回：

## 参数错误

```
{
 "code":"xxx",
 "msg":"参数错误",
 "success":false
}
```

可能原因：

- gid为空；
- tiao为空；
- 参数格式错误。

------

## 无引用数据

```
{
 "total":"0",
 "resultitem":[]
}
```

表示：

该法规条款暂无地方法规引用记录。

## 接口定位总结

> **getdffllink接口用于查询“某一法规条款被哪些地方法规引用”，通过法规gid和条款号建立法规之间的引用关系，是法规知识图谱和法规关联分析的重要基础接口。**
