# 裁判规则（案例要旨库）全文及基本信息查询接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

**案例要旨库详情查询接口（裁判规则查询接口）**

------

### 1.2 接口地址

```
POST https://m-v2.faxin.cn/m/v6/api/alyz/content
```

------

### 1.3 功能说明

根据案例要旨库唯一标识 `gid`，查询裁判规则（案例要旨）详细内容。

该接口对应法信中的：

> **案例要旨库**

业务名称：

> **裁判规则**

返回内容包括：

- 裁判规则标题；
- 案例名称；
- 案件来源；
- 审理法院；
- 审理日期；
- 案件分类；
- 裁判规则正文；
- 案例注解；
- 基本案情；
- 法律依据关联；
- 全文内容。

主要应用场景：

- 裁判规则展示；
- 类案检索；
- AI法律问答；
- 裁判观点抽取；
- 法律知识图谱；
- RAG知识库建设。

# 10. 裁判规则内容字段

## 10.1 裁判规则摘要

字段：

```
alyz_content
```

说明：

存储案件核心裁判观点。

示例：

```
《刑法》分则并无针对海上交通肇事犯罪的专门条款...
```

内容特点：

包含法规关联：

```
<a 
fid="A192308"
tiao="133"
class="flink">
第一百三十三条
</a>
```

表示：

引用法规：

```
法规ID:
A192308

条款:
133
```

可关联法规接口：

```
裁判规则
    |
    ↓
引用法规
    |
    ↓
具体法条
```

# 19. 数据处理建议

## 19.1 HTML正文处理

接口返回：

- `alyz_content`
- `fypl`
- `fulltext`

均为HTML。

建议保存两个版本：

### 原始版本

```
fulltext_html
```

保留：

- 法规链接；
- 引用关系；
- HTML结构。

### 清洗版本

```
fulltext_text
```

用于：

- ES全文检索；
- 向量化；
- RAG。

# 接口总结

| 项目     | 说明                           |
| -------- | ------------------------------ |
| 接口名称 | 案例要旨库详情接口             |
| 业务名称 | 裁判规则                       |
| 请求方式 | POST                           |
| 核心参数 | gid                            |
| 返回内容 | 裁判规则+案例全文+案例注解     |
| 正文格式 | HTML                           |
| 数据粒度 | 单条裁判规则                   |
| 主要用途 | 类案检索、AI审判辅助、知识图谱 |
| 关键价值 | 连接法规、案例、裁判观点       |

该接口属于法信**案例要旨库（裁判规则库）详情服务接口**，是构建“法规—裁判规则—案例—司法观点”法律知识体系的重要数据接口。
