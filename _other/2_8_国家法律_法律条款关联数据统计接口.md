# 法律条款关联数据统计接口技术说明文档

------

# 1. 接口概述

## 1.1 接口名称

法律条款关联数据统计接口（linkcount）

------

## 1.2 接口地址

```
POST https://m-v2.faxin.cn/m/v6/api/link/linkcount
```

## 1.3 功能介绍

该接口用于根据指定法规文件的：

- 法规唯一标识 `gid`
- 条款编号 `tiao`

查询该条款对应的**关联数据类型及数量统计信息**。

接口返回当前条款关联的数据资源分类及数量，例如：

- 国家法律数量
- 裁判规则数量
- 期刊文章数量
- 其他关联资源数量

该接口主要用于法律详情页中的：

> “关联内容数量展示”

例如：

```
关联内容：

国家法律(2)
裁判规则(11)
期刊(258)
```

用户点击后进入对应关联数据列表。

------

# 2. 请求说明

## 2.1 请求方式

| 项目         | 说明             |
| ------------ | ---------------- |
| HTTP方法     | POST             |
| Content-Type | application/json |
| 请求参数     | JSON             |
| 返回格式     | JSON             |

------

# 3. 请求参数

## 3.1 请求Body示例

```
{
    "gid":"A192308",
    "tiao":"5",
    "type":""
}
```

------

## 3.2 参数定义

| 参数名 | 类型   | 是否必填 | 说明             |
| ------ | ------ | -------- | ---------------- |
| gid    | String | 是       | 法规文件唯一ID   |
| tiao   | String | 是       | 条款编号         |
| type   | String | 否       | 关联类型过滤参数 |

------

# 4. 参数详细说明

## 4.1 gid

### 含义

法规文件唯一标识。

来源：

- 国家法律搜索接口
- 法律正文接口

示例：

```
{
    "gid":"A192308"
}
```

对应：

```
中华人民共和国刑法(1997年修订)
```

------

## 4.2 tiao

### 含义

当前法规条款编号。

示例：

```
{
    "tiao":"5"
}
```

表示：

```
中华人民共和国刑法 第五条
```

传值规则：

| 条款           | 参数 |
| -------------- | ---- |
| 第一条         | 1    |
| 第五条         | 5    |
| 第三百五十一条 | 351  |

------

## 4.3 type

### 含义

关联数据类型过滤参数。

当前请求示例：

```
{
    "type":""
}
```

表示：

查询全部关联类型。

该参数通常用于：

- 指定关联资源类型
- 控制返回范围

------

# 5. 返回结构说明

## 5.1 返回示例

```
{
    "msg":"成功",
    "code":"0",
    "data":{
        "linkcount":
        "<li flag=\"linkzyfl\">国家法律(2)</li>
         <li flag=\"linkalyz\">裁判规则(11)</li>
         <li flag=\"linkflqk\">期刊(258)</li>"
    },
    "success":true
}
```

------

# 6. 返回字段说明

## 6.1 顶层字段

| 字段    | 类型    | 说明         |
| ------- | ------- | ------------ |
| msg     | String  | 返回消息     |
| code    | String  | 状态码       |
| data    | Object  | 业务数据     |
| success | Boolean | 接口调用结果 |

------

# 7. data字段说明

返回结构：

```
{
    "linkcount":"HTML字符串"
}
```

| 字段      | 类型   | 说明                 |
| --------- | ------ | -------------------- |
| linkcount | String | 关联资源数量统计HTML |

------

# 8. linkcount字段说明

## 8.1 数据格式

该字段不是JSON数组，而是HTML列表字符串。

示例：

```
<li flag="linkzyfl">
    国家法律(2)
</li>

<li flag="linkalyz">
    裁判规则(11)
</li>

<li flag="linkflqk">
    期刊(258)
</li>
```

------

## 8.2 HTML属性说明

| 属性 | 说明             |
| ---- | ---------------- |
| flag | 关联资源类型标识 |
| 文本 | 资源名称及数量   |

------

# 9. 关联资源类型说明

根据返回示例：

| flag     | 名称     | 说明         |
| -------- | -------- | ------------ |
| linkzyfl | 国家法律 | 关联法律法规 |
| linkalyz | 裁判规则 | 关联案例规则 |
| linkflqk | 期刊     | 关联学术期刊 |

------

# 10. 返回数据解析示例

接口返回：

```
<li flag="linkzyfl">
国家法律(2)
</li>

<li flag="linkalyz">
裁判规则(11)
</li>
```

解析后：

```
[
    {
        "type":"linkzyfl",
        "name":"国家法律",
        "count":2
    },
    {
        "type":"linkalyz",
        "name":"裁判规则",
        "count":11
    }
]
```

建议前端或服务端进行HTML解析后使用。

------

# 11. 调用流程

```
                 法律搜索
                     |
                     |
                 获取gid
                     |
                     ↓
              获取条款编号tiao
                     |
                     ↓
          /link/linkcount接口
                     |
                     ↓
          获取关联资源数量
                     |
        --------------------------
        |            |           |
     国家法律     裁判规则      期刊
        |
        ↓
 点击进入对应关联列表
```

# 12. 与其他接口关系

| 接口             | 作用                 |
| ---------------- | -------------------- |

完整调用链：

```
法规(gid)
 |
 |
条款(tiao)
 |
 +----------------+
 |                |

 |                |
fulltext      linkcount
                  |
                  |
        国家法律/案例/期刊数量
```

# 13. 开发注意事项

## 13.1 linkcount不是JSON数组

返回：

```
{
 "linkcount":"<li>...</li>"
}
```

不是：

```
[
 {
   "name":"国家法律",
   "count":2
 }
]
```

开发时需要：

- HTML解析
- 正则提取
- DOM解析

------

## 13.2 数量可能为空

某条款可能无关联资源：

可能返回：

```
""
```

或者：

```
暂无关联数据
```

需要兼容。

------

## 13.3 数量仅表示资源数量

例如：

```
国家法律(2)
```

表示：

当前条款关联：

```
国家法律资源 = 2条
```

不包含具体内容。

具体内容需要调用对应列表接口。

------

# 14. 接口定位总结

该接口属于法信法律知识库中的：

**“法律条款关联资源统计接口”**

数据关系：

```
法规文件(gid)
       |
       |
     条款(tiao)
       |
       |
  +----+-----+------+
  |          |      |
国家法律   案例    期刊
  |          |      |
数量       数量    数量
```

主要作用：

- 法律详情页关联入口展示
- 用户快速了解关联资源规模
- 为法律知识图谱提供关联统计信息
- 支撑AI法律检索中的关联扩展能力

------

与前几个接口组合后，可形成完整法律知识服务链：

```
搜索法规
   ↓
获取gid
   ↓
查询条款
   ↓
获取正文
   ↓
查询关联数量
   ↓
查询关联资源
   ↓
形成法律知识网络
```
