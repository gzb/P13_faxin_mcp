# 法规条款关联国家法律列表查询接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

法规条款引用国家法律查询接口

------

### 1.2 接口地址

```
POST https://m-v2.faxin.cn/m/v6/api/fl/zyfl/GetZyflLinkList
```

------

### 1.3 接口功能

根据指定法规文件的 `gid` 和具体条款 `tiao`，查询**引用该法规条款的国家法律数据列表**。

该接口用于实现：

- 法规条款关联法律文件查询
- 法律依据追溯
- 法规之间引用关系展示
- 法律知识图谱构建
- AI法律检索中的规范关联扩展

业务逻辑：

```
                  法规文件
                     |
                     |
              gid + tiao
                     |
                     |
             查询引用关系
                     |
                     |
              国家法律库
                     |
                     |
          返回关联法律文件列表
```

例如：

输入：

```
{
    "gid":"A192308",
    "tiao":"10"
}
```

表示：

查询法规 `A192308` 第 `10` 条被哪些国家法律文件引用。

返回：

```
中华人民共和国相关法律、司法解释等规范文件列表
```

# 3. 请求参数说明

## 3.1 请求JSON格式

```
{
    "pagenum":1,
    "pagesize":10,
    "gid":"A192308",
    "tiao":"10"
}
```

------

## 3.2 参数定义

| 参数名称 | 类型   | 必填 | 示例    | 说明              |
| -------- | ------ | ---- | ------- | ----------------- |
| gid      | string | 是   | A192308 | 法规文件唯一标识  |
| tiao     | string | 是   | 10      | 法规条款编号      |
| pagenum  | int    | 是   | 1       | 分页页码，从1开始 |
| pagesize | int    | 是   | 10      | 每页返回数量      |

------

# 17. 开发注意事项

## 17.1 gid必须使用法规ID

正确：

```
{
 "gid":"A192308"
}
```

不要传：

```
国家法律gid
裁判规则gid
期刊gid
```

------

## 17.2 tiao类型为字符串

正确：

```
"tiao":"10"
```

错误：

```
"tiao":10
```

------

## 17.3 catalog字段较大

建议：

数据库：

```
TEXT / CLOB
```

不要使用普通VARCHAR。

------

## 17.4 hisinfo用于版本链展示

可用于：

- 法律修订追踪
- 新旧版本切换
- 法律时效判断

## 总结

该接口是法信法律知识体系中的**“规范引用关系查询接口”**，用于建立：

> **一个法规条款被哪些国家法律规范引用**

的关联关系。

结合：

- `getflqklink`（法规 → 期刊）
- `getalyzlink`（法规 → 裁判规则）
- `GetZyflLinkList`（法规 → 国家法律）

可以形成完整的法律知识关联网络：

```
              法规条款
                  |
     +------------+------------+
     |            |            |
     v            v            v

  国家法律     裁判规则      学术研究

  规范依据     实务应用      理论解释
```

适用于法律搜索、智能问答、AI辅助审判、法律知识图谱等应用场景。
