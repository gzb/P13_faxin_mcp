# 法信法规历史版本查询接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

**法规条文历史版本查询接口**

### 1.2 接口用途

用于根据法规条目编号（`gid`）查询该条款的历史修订版本信息。

接口返回指定法规条款历次版本记录，包括：

- 历史版本法规编号
- 条款编号
- 修订日期
- 修改状态
- 条文摘要
- 历史版本跳转信息

主要用于：

- 法规详情页“历史版本”展示
- 法规新旧版本对比
- 法规修订轨迹查询
- 历史法规内容回溯

------

# 2. 接口信息

## 2.1 请求地址

```
https://m-v2.faxin.cn/m/v6/api/fl/zyfl/gethistoryinfo
```

## 2.2 请求方式

```
GET
```

## 2.3 请求参数

| 参数名 | 类型   | 必填 | 说明               | 示例    |
| ------ | ------ | ---- | ------------------ | ------- |
| gid    | String | 是   | 当前法规条目标识ID | A190401 |
| tiao   | String | 是   | 条文编号           | 1       |

### 请求示例

```
GET https://m-v2.faxin.cn/m/v6/api/fl/zyfl/gethistoryinfo?gid=A190401&tiao=1
```

------

# 3. 返回数据说明

## 3.1 返回结构

```
{
    "msg": "成功",
    "code": "0",
    "data": {
        "hisinfo": []
    },
    "success": true
}
```

## 3.2 返回字段说明

### 一级字段

| 字段    | 类型    | 说明              |
| ------- | ------- | ----------------- |
| msg     | String  | 返回消息          |
| code    | String  | 状态码，0表示成功 |
| success | Boolean | 请求是否成功      |
| data    | Object  | 数据对象          |

------

## 3.3 data对象

| 字段    | 类型  | 说明         |
| ------- | ----- | ------------ |
| hisinfo | Array | 历史版本列表 |

------

## 3.4 hisinfo数组对象

单条历史版本信息结构：

```
{
    "gid":"A190401",
    "tiao":"1",
    "strdate":"2012-12-28",
    "status":"未修改",
    "intro":"第一条……",
    "contentText":"<a href='javascript:FXC(...)'>法规名称</a>"
}
```

字段说明：

| 字段        | 类型   | 说明                 | 示例                             |
| ----------- | ------ | -------------------- | -------------------------------- |
| gid         | String | 历史版本法规ID       | A190401                          |
| tiao        | String | 条款编号             | 1                                |
| strdate     | String | 发布时间/修订日期    | 2012-12-28                       |
| status      | String | 修改状态             | 未修改                           |
| intro       | String | 条文内容摘要         | 第一条【立法宗旨】...            |
| contentText | String | HTML格式版本链接信息 | `<a href='javascript:FXC(...)'>` |

# 5. 业务逻辑说明

## 5.1 查询逻辑

输入：

```
当前法规ID + 条款编号
```

例如：

```
gid=A190401
tiao=1
```

系统查询：

```
当前法规条款
        |
        |
        ↓
关联历史法规版本
        |
        |
        ↓
返回所有历史版本列表
```

# 9. 开发注意事项

## 9.1 contentText字段处理

该字段为HTML内容：

例如：

```
<a href='javascript:FXC("A190401","1")'>
中华人民共和国劳动合同法(2012年修正)
</a>
```

后端开发建议：

不要直接作为可信HTML渲染。

建议解析：

提取：

```
gid
tiao
title
```

形成结构化数据：

```
{
    "gid":"A190401",
    "tiao":"1",
    "title":"中华人民共和国劳动合同法(2012年修正)"
}
```

------

## 9.2 日期格式

字段：

```
strdate
```

格式：

```
yyyy-MM-dd
```

示例：

```
2012-12-28
```

------

## 9.3 intro字段

用途：

用于列表展示摘要。

特点：

- 包含中文全角空格
- 包含条款编号
- 可能包含特殊字符

建议：

展示前进行：

```
trim()
```

处理。
