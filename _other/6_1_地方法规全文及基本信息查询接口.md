# 地方法规全文及基本信息查询接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

地方法规全文查询接口

### 1.2 接口地址

```
POST https://m-v2.faxin.cn/m/v6/api/fl/dffl/content
```

------

## 1.3 功能描述

根据**地方法规唯一标识 gid**，返回对应地方性法规/地方规范性文件的：

- 基本信息；
- 发布信息；
- 制定机构；
- 效力状态；
- 分类信息；
- 法规全文内容。

该接口主要用于：

- 地方法规详情页展示；
- 法规全文检索后的内容加载；
- 法规知识库数据同步；
- 法规全文数据采集。

# 18. 与其他接口关系

该接口属于地方性法规数据服务接口。

关联接口：

| 接口         | 用途                     |
| ------------ | ------------------------ |
| getdffllink  | 查询引用该法规的关联法规 |
| dffl/content | 获取法规全文             |

典型调用流程：

```
法规关联查询

      |
      |
getdffllink

      |
返回gid列表

      |
      |
dffl/content

      |
获取法规全文
```

# 19. 开发建议

## 19.1 gid作为主键保存

建议数据表设计：

```
local_law
-----------------
gid
title
publish_date
department
status
content
```

其中：

```
gid
```

作为唯一键。

------

## 19.2 fulltext处理建议

由于返回HTML：

建议处理流程：

```
HTML全文
   |
HTML解析
   |
去除标签
   |
保存纯文本
   |
建立全文索引
```

适用于：

- Elasticsearch全文检索；
- AI知识库构建；
- RAG向量化。

------

## 19.3 注意事项

1. `fulltext`字段较长，不建议直接展示限制长度。
2. 返回内容包含HTML，需要前端渲染或后端清洗。
3. `gid`不可自行生成，应来源于接口。
4. 部分法规可能存在历史版本，需要结合 `hisinfo` 处理。

------

# 20. 接口总结

dffl/content接口用于根据地方法规gid获取法规详细内容，是地方性法规库的数据详情接口。返回内容包括法规基本信息、制定机构、效力状态、分类信息以及HTML格式全文，可用于法规展示、全文检索、知识库建设和AI应用场景。
