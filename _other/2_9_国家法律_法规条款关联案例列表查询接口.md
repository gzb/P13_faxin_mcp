# 法规条款关联案例列表查询接口技术说明文档

------

# 1. 接口概述

## 1.1 接口名称

**法规条款关联案例查询接口**

接口功能：

根据指定法规文件及具体条款，查询**引用该法规条款的案例数据列表**。

输入：

- `statuteId`：法规文件GID
- `stripId`：法规条款编号

输出：

返回引用该法规条款的案例基本信息，包括：

- 案例标题
- 案号
- 审理法院
- 裁判日期
- 案例唯一ID

支持分页查询。

------

# 2. 接口地址

## 2.1 请求地址

```
POST

https://m-v2.faxin.cn/m/v6/api/statute/info/case/getStatuteIdCaseList
```


# 3. 请求方式

| 项目         | 说明             |
| ------------ | ---------------- |
| HTTP方法     | POST             |
| Content-Type | application/json |
| 请求参数     | JSON Body        |
| 返回格式     | JSON             |

------

# 4. 请求参数说明

## 4.1 请求示例

```
{
    "statuteId":"A192308",
    "stripId":"5",
    "page":1,
    "size":10
}
```

------

## 4.2 参数列表

| 参数名    | 类型    | 是否必填 | 说明                        |
| --------- | ------- | -------- | --------------------------- |
| statuteId | String  | 是       | 法规文件唯一ID，对应法规gid |
| stripId   | String  | 是       | 法规条款编号，对应tiao      |
| page      | Integer | 否       | 页码，从1开始               |
| size      | Integer | 否       | 每页返回数量                |

------

# 5. 参数详细说明

## 5.1 statuteId

### 含义

法规文件唯一标识。

来源：

- 国家法律搜索接口
- 法律正文接口

示例：

```
{
 "statuteId":"A192308"
}
```

对应：

```
中华人民共和国刑法(1997年修订)
```

------

## 5.2 stripId

### 含义

法规条款编号。

示例：

```
{
 "stripId":"5"
}
```

表示：

```
中华人民共和国刑法 第五条
```

对应关系：

| 法律条款       | stripId |
| -------------- | ------- |
| 第一条         | 1       |
| 第五条         | 5       |
| 第三百五十一条 | 351     |

------

## 5.3 page

### 含义

分页页码。

示例：

```
{
 "page":1
}
```

说明：

- 第一页传1
- 第二页传2

------

## 5.4 size

### 含义

每页返回数据量。

示例：

```
{
 "size":10
}
```

表示：

一次返回10条案例。

# 9. 数据业务含义

该接口返回：

> 引用了指定法规条款的裁判案例。

数据关系：

```
法规文件
   |
   |
 gid(statuteId)
   |
   |
法规条款
   |
   |
 tiao(stripId)
   |
   |
引用该条款的案例
   |
   +----------------+
   |                |
案例1             案例2
   |
案例N
```

例如：

请求：

```
{
 "statuteId":"A192308",
 "stripId":"5"
}
```

含义：

查询：

```
中华人民共和国刑法
第五条
```

被哪些案例引用。

返回：

```
案例总数：813
```

------

# 10. 分页查询说明

假设：

```
total = 813
size = 10
```

分页结果：

| page | 返回范围 |
| ---- | -------- |
| 1    | 1-10     |
| 2    | 11-20    |
| 3    | 21-30    |
| ...  | ...      |
| 82   | 811-813  |

计算：

```
总页数 = ceil(total / size)
```

# 13. 开发注意事项

## 13.1 gid字段注意

法规接口中的：

```
gid
```

对应本接口：

```
statuteId
```

不要传案例gid。

------

## 13.2 stripId字段注意

本接口参数：

```
stripId
```

对应：

其他接口中的：

```
tiao
```

例如：

其他接口：

```
{
 "gid":"A192308",
 "tiao":"5"
}
```

转换：

```
{
 "statuteId":"A192308",
 "stripId":"5"
}
```

------

## 13.3 案例gid不可直接替代法规gid

返回：

```
{
 "gid":"ZebhHAMhaV/kHkmr6x1aOg=="
}
```

该gid为：

```
案例ID
```

不是：

```
法规ID
```

用于后续：

- 案例详情查询
- 案例跳转

------

# 14. 接口定位总结

该接口属于法信法律知识库：

**“法规条款 → 裁判案例关联查询服务”**

核心作用：

- 展示法律条款引用案例
- 构建法律知识图谱关系
- 支撑案例辅助检索
- 支撑AI法律问答中的案例推荐

知识关系模型：

```
             法规
              |
              |
          法规条款
              |
     ------------------
     |                |
  裁判案例          解释文章
     |
     |
  案例详情
```

该接口是法律知识图谱中：

**法规节点 → 案例节点**

的重要关联接口。
