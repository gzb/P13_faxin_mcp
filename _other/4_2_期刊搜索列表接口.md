# 法律期刊搜索列表接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

**法律期刊搜索列表接口**

### 1.2 接口地址

```
POST http://m-v2.faxin.cn/m/v6/api/jrflqk/searchdata
```

### 1.3 功能描述

该接口用于查询法信平台中的**法律期刊数据**，根据期刊分类、关键词、作者、年份、期号、全文内容等条件进行检索，返回符合条件的法律期刊文章列表信息。

支持：

- 核心期刊查询
- 非核心期刊查询
- 实务期刊查询
- 法学期刊查询
- 大学学报查询
- 学位论文查询
- 英文期刊查询
- 按作者、机构、年份、关键词等条件组合检索
- 分页查询

# 4. 期刊分类（libid）

`libid`用于指定查询的期刊数据范围。

| libid  | 类型       |
| ------ | ---------- |
| 040101 | 核心期刊   |
| 040106 | 非核心期刊 |
| 040102 | 实务期刊   |
| 040103 | 法学期刊   |
| 040104 | 大学学报   |
| 040107 | 学位论文   |
| 040105 | 英文期刊   |

示例：

查询核心期刊：

```
{
    "libid":"040101"
}
```

查询法学期刊：

```
{
    "libid":"040103"
}
```

# 9. 分页说明

接口采用传统页码分页方式：

| 参数     | 说明          |
| -------- | ------------- |
| pagesize | 每页数量      |
| pagenum  | 页码，从1开始 |
| total    | 总记录数      |

示例：

```
{
    "pagesize":20,
    "pagenum":"3"
}
```

表示：

> 获取第3页，每页20篇文章。

------

# 10. gid字段说明

返回结果中的：

```
gid
```

为期刊文章唯一标识。

例如：

```
{
    "gid":"F788435"
}
```

用途：

- 查询期刊文章全文
- 构建法律知识库
- 建立文章引用关系
- AI检索增强（RAG）

# 12. 开发注意事项

## 12.1 pagehtml字段

接口返回：

```
pagehtml
```

为Web页面分页展示代码。

对于：

- 后端服务
- APP接口
- MCP服务
- 数据同步任务

建议忽略该字段，使用：

```
total
pagesize
pagenum
```

自行实现分页。

------

## 12.2 keyword与高级搜索

普通搜索：

```
{
 "keyword":"人工智能"
}
```

高级搜索：

```
{
 "isadvsearch":"true",
 "keytitle":"人工智能",
 "zuozhe_name":"张三",
 "year":"2025"
}
```

建议：

- 简单搜索场景使用 `keyword`
- 精准检索使用高级字段组合
