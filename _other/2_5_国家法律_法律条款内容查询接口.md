# 法律条款内容查询接口技术说明文档

------

# 1. 接口概述

## 1.1 接口名称

法律条款内容查询接口

## 1.2 接口地址

```
POST http://m-v2.faxin.cn/m/v6/api/fl/zyfl/getcommondatabygidtiao
```

------

## 1.3 功能介绍

该接口用于根据**法律法规文件ID（gid）\**和\**条文编号（tiao）**，查询指定法律条款的详细内容。

接口返回对应条款的：

- 法规基本信息
- 制定机关
- 发布日期
- 发文字号
- 法律标题
- 法律分类
- 条款正文内容
- 生效日期
- 时效状态
- 效力等级

该接口主要用于：

- 法律详情页按条展示
- 法律条文定位查询
- AI法律问答精准引用
- 法律知识库条款切片
- 法律法规智能检索

------

# 2. 请求说明

## 2.1 请求方式

| 项           | 内容             |
| ------------ | ---------------- |
| HTTP方法     | POST             |
| Content-Type | application/json |
| 请求参数格式 | JSON             |
| 返回格式     | JSON             |

------

## 2.2 请求示例

```
POST /m/v6/api/fl/zyfl/getcommondatabygidtiao

Content-Type: application/json
```

请求Body：

```
{
    "gid":"A192308",
    "tiao":"351"
}
```

------

# 3. 请求参数说明

| 参数名 | 类型   | 必填 | 说明               |
| ------ | ------ | ---- | ------------------ |
| gid    | String | 是   | 法规文件唯一标识ID |
| tiao   | String | 是   | 条文编号           |

------

## 3.1 gid说明

`gid` 为法律法规文件唯一标识。

来源：

- 国家法律搜索列表接口
- 国家法律正文接口

示例：

```
{
    "gid":"A192308"
}
```

对应：

```
中华人民共和国刑法(1997年修订)
```

------

## 3.2 tiao说明

`tiao` 表示法律条文编号。

例如：

```
{
    "tiao":"351"
}
```

表示查询：

```
第三百五十一条
```

------

# 4. 返回参数说明

## 4.1 顶层结构

```
{
    "msg":"",
    "code":"",
    "data":{},
    "success":true
}
```

| 字段    | 类型    | 说明         |
| ------- | ------- | ------------ |
| msg     | String  | 返回消息     |
| code    | String  | 返回状态码   |
| data    | Object  | 返回数据     |
| success | Boolean | 请求是否成功 |

------

## 4.2 状态码说明

| code | 说明     |
| ---- | -------- |
| 0    | 查询成功 |
| 其他 | 查询失败 |

------

# 5. data返回结构说明

返回：

```
{
    "fileinfo":{}
}
```

| 字段     | 类型   | 说明               |
| -------- | ------ | ------------------ |
| fileinfo | Object | 法律文件及条款信息 |

------

# 6. fileinfo字段说明

| 字段       | 类型   | 说明         |
| ---------- | ------ | ------------ |
| gid        | String | 法律文件ID   |
| title      | String | 法律文件名称 |
| fulltext   | String | 当前条款正文 |
| fwzh       | String | 发文字号     |
| fdate      | String | 发布日期     |
| ssrq       | String | 施行日期     |
| fdep_id    | Array  | 制定机关     |
| sort_id    | Array  | 主题分类     |
| shixiao_id | Array  | 时效状态     |
| xiaoli_id  | Array  | 效力等级     |

------

# 7. 字段详细说明

## 7.1 gid

示例：

```
"gid":"A192308"
```

说明：

法律法规唯一编号。

------

## 7.2 title

示例：

```
"title":"中华人民共和国刑法(1997年修订)"
```

说明：

法律文件名称。

------

## 7.3 fulltext（核心字段）

示例：

```
"fulltext":"第三百五十一条 【非法种植毒品原植物罪】非法种植罂粟、大麻等毒品原植物的，一律强制铲除......"
```

说明：

返回指定条文完整内容。

特点：

- 已根据`tiao`定位
- 返回单条法律正文
- 可直接用于页面展示
- 可作为AI检索知识片段

------

## 7.4 fdep_id（制定机关）

返回格式：

```
[
    {
        "value":"全国人民代表大会",
        "key":"001"
    }
]
```

字段：

| 字段  | 说明     |
| ----- | -------- |
| key   | 机构编码 |
| value | 机构名称 |

------

## 7.5 fdate（发布日期）

示例：

```
"fdate":"1997-03-14 00:00:00"
```

说明：

法律公布日期。

------

## 7.6 fwzh（发文字号）

示例：

```
"fwzh":"中华人民共和国主席令第八十三号"
```

说明：

发布法律文件编号。

------

## 7.7 ssrq（施行日期）

示例：

```
"ssrq":"1997-10-01 00:00:00"
```

说明：

法律正式生效日期。

------

## 7.8 sort_id（主题分类）

示例：

    {

    }

------

常见状态：

| key  | value    |
| ---- | -------- |

| 其他 | 其他状态 |

# 9. 接口调用流程

```
        法律搜索接口
              |
              |
          获取gid
              |
              ↓
  getcommondatabygidtiao
              |
              |
       输入gid+tiao
              |
              ↓
       返回单条法规内容
              |
       ----------------
       |              |
    条款正文       法规元数据
```

------

# 10. 与其他接口关系

| 接口                 | 作用                     |
| -------------------- | ------------------------ |
| 国家法律搜索列表接口 | 查询法律列表，获取gid    |
| 国家法律正文接口     | 获取完整法规             |
| 本接口               | 根据gid+tiao获取指定条款 |
| 法条释义接口         | 获取专家解释内容         |

推荐流程：

```
法律库检索
    ↓
获取法规gid
    ↓
查询具体条款
    ↓
获取fulltext
    ↓
关联法条释义
```

# 11. 开发注意事项

## 11.1 条款编号处理

`tiao` 为数字字符串。

例如：

| 输入 | 对应           |
| ---- | -------------- |
| 1    | 第一条         |
| 351  | 第三百五十一条 |
| 500  | 第五百条       |

不要传：

```
第三百五十一条
```

应传：

```
351
```

------

## 11.2 fulltext字段建议

建议数据库保存：

| 字段     | 用途     |
| -------- | -------- |
| gid      | 法规关联 |
| tiao     | 条款编号 |
| fulltext | 条款正文 |
| title    | 法规名称 |

方便：

- 法律知识库构建
- ES全文检索
- RAG向量检索

------

## 11.3 时效性处理

接口可能返回：

```
"shixiao_id":"已被修改"
```

业务展示时建议提示：

> 当前条款所属法规已被修改，请关注最新版本。

## 接口定位

该接口是法信国家法律库中的**“法规文件 → 精确条款内容”查询接口**，用于实现法律条文级检索、引用、展示及AI法律应用场景。
