# 法条条文释义详情接口技术说明文档

------

# 1. 接口概述

## 1.1 接口名称

法条条文释义详情查询接口

------

## 1.2 接口地址

```
POST http://m-v2.faxin.cn/m/v6/api/ftsy/tiaocontent
```

------

## 1.3 功能介绍

该接口用于获取指定法律条文对应的**释义详情内容**。

通过：

- 法律文章ID（`gid`）
- 条文编号（`tiao`）
- 法条释义来源类型（`type`）

查询指定来源下的法律条文解释全文。

接口主要返回：

- 条文释义标题
- 对应法律条文
- 释义正文
- 来源信息
- 主编信息
- 出版机构
- 权限状态

适用于：

- 法律法规详情展示
- 法条释义阅读
- AI法律知识增强
- 法律智能问答
- 法律知识库构建

------

# 2. 请求说明

## 2.1 请求方式

| 参数         | 内容             |
| ------------ | ---------------- |
| HTTP方法     | POST             |
| Content-Type | application/json |
| 请求格式     | JSON             |
| 返回格式     | JSON             |

------

# 3. 请求参数说明

## 3.1 输入参数

请求参数通过Body传递JSON格式。

| 参数名 | 类型   | 必填 | 说明                                     |
| ------ | ------ | ---- | ---------------------------------------- |
| gid    | String | 是   | 法律文章ID                               |
| type   | String | 是   | 法条释义来源类型，从法条释义来源接口获取 |
| tiao   | String | 是   | 条文编号                                 |

------

## 3.2 请求示例

```
{
    "gid":"A297386",
    "tiao":"1",
    "type":"学者论著/《中华人民共和国行政处罚法》释义/中国民主法制出版社"
}
```

------

# 4. 参数说明

## 4.1 gid

说明：

- 法律文章唯一标识。
- 来源于法律正文接口或法条释义来源接口。

示例：

```
{
    "gid":"A297386"
}
```

------

## 4.2 type

说明：

- 标识具体释义来源。
- 必须使用接口：

```
/m/v6/api/ftsy/getftsyrightlist
```

返回的 `type` 字段。

例如：

```
{
    "type":"《中华人民共和国行政处罚法》释义"
}
```

------

## 4.3 tiao

说明：

- 指定法律第几条。
- 与法律原文条款对应。

示例：

```
1
```

表示：

> 查询第1条法律释义。

------

# 5. 返回参数说明

## 5.1 顶层返回结构

| 字段    | 类型    | 说明         |
| ------- | ------- | ------------ |
| msg     | String  | 返回消息     |
| code    | String  | 返回状态码   |
| data    | Object  | 返回数据     |
| success | Boolean | 请求是否成功 |

------

## 5.2 状态码说明

| code | 说明     |
| ---- | -------- |
| 0    | 请求成功 |
| 其他 | 请求失败 |

------

# 6. data数据结构说明

返回：

```
{
    "gid":"",
    "total":"",
    "syinfos":{},
    "isCanBrowse":""
}
```

| 字段        | 类型   | 说明                 |
| ----------- | ------ | -------------------- |
| gid         | String | 法条释义ID           |
| total       | String | 该来源下释义数量     |
| syinfos     | Object | 当前条文释义详细内容 |
| isCanBrowse | String | 内容浏览权限         |

------

# 7. syinfos字段说明

## 7.1 数据结构

```
{
    "id":"",
    "author":"",
    "content":"",
    "title":"",
    "tiao_title":"",
    "editor_name":"",
    "publisher":""
}
```

------

## 7.2 字段说明

| 字段        | 类型   | 说明             |
| ----------- | ------ | ---------------- |
| id          | String | 释义记录ID       |
| author      | String | 释义来源         |
| content     | String | 释义正文         |
| title       | String | 释义标题         |
| tiao_title  | String | 对应法律条文标题 |
| editor_name | String | 主编             |
| publisher   | String | 出版社/出版机构  |

------

# 8. 详细字段说明

## 8.1 author（来源）

示例：

```
"author":"《中华人民共和国行政处罚法》释义"
```

说明：

表示该解释内容来源的书籍或资料名称。

------

## 8.2 title（标题）

示例：

```
"title":"中华人民共和国行政处罚法（2021年修订）第二条释义"
```

说明：

表示：

```
法律名称 + 修订版本 + 条文编号 + 释义
```

------

## 8.3 tiao_title（条文标题）

示例：

```
"tiao_title":
"第二条 行政处罚是指行政机关依法对违反行政管理秩序的公民、法人或者其他组织，以减损权益或者增加义务的方式予以惩戒的行为。"
```

说明：

对应法律正文中的具体条款。

------

## 8.4 content（释义正文）

示例：

```
"content":"【释义】本条是关于行政处罚定义的规定..."
```

说明：

返回完整专家解释文本。

内容可能包含：

- 立法背景
- 条文解释
- 制度分析
- 实务说明
- 专家观点

该字段适合：

- 全文展示
- 文本索引
- AI知识库构建

------

## 8.5 editor_name（主编）

示例：

```
"editor_name":"许安标"
```

说明：

对应释义出版物主编。

------

## 8.6 publisher（出版社）

示例：

```
"publisher":"中国民主法制出版社"
```

说明：

对应出版机构信息。

------

# 9. 权限字段说明

## isCanBrowse

字段：

```
"isCanBrowse":"1"
```

说明：

控制用户是否可以查看完整释义。

| 值   | 说明             |
| ---- | ---------------- |
| 1    | 允许查看完整内容 |
| 0    | 限制查看         |

权限规则：

| 用户状态       | 内容                    |
| -------------- | ----------------------- |
| 未登录用户     | 仅返回部分内容（约1/3） |
| 已登录但无权限 | 仅返回部分内容（约1/3） |
| 有权限用户     | 返回完整内容            |

------

# 12. 开发注意事项

## 12.1 type参数处理

不要自行拼接：

错误：

```
type=中华人民共和国行政处罚法释义
```

推荐：

直接使用来源接口返回：

```
type=学者论著/《中华人民共和国行政处罚法》释义/中国民主法制出版社
```

------

## 12.2 content字段处理

`content` 为长文本字段：

建议：

- 数据库存储使用TEXT/CLOB类型；
- 保留原始文本；
- 建立全文索引；
- AI检索时进行分段切片。

------

## 12.3 与其他接口关系

接口依赖：

| ---------------- | ------------ |

| 法律正文接口     | 获取法律正文 |
| getftsyrightlist | 获取释义来源 |
| tiaocontent      | 获取释义全文 |
