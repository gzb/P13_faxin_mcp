# 法规条款关联期刊列表查询接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

法规文件引用期刊查询接口

### 1.2 接口地址

```
POST https://m-v2.faxin.cn/m/v6/api/jrflqk/getflqklink
```

### 1.3 接口功能

根据指定法规文件（通过 `gid` 标识）中的具体条款（通过 `tiao` 标识），查询引用该法规条款的**期刊文章数据列表**。

该接口主要用于实现：

- 法规条款 → 引用文献查询
- 法规关联期刊展示
- 法律知识关联分析
- 法规影响文献追踪

例如：

输入：

```
法规ID：A192308
条款：第5条
```

返回：

```
引用《刑法》第5条相关研究文章列表
```

支持分页查询，通过 `pagenum` 和 `pagesize` 参数控制返回数据量。

# 3. 请求参数

## 3.1 请求JSON结构

```
{
    "pagenum": 1,
    "pagesize": 10,
    "gid": "A192308",
    "tiao": "5"
}
```

------

## 3.2 参数说明

| 参数名称 | 类型    | 是否必填 | 示例    | 说明               |
| -------- | ------- | -------- | ------- | ------------------ |
| gid      | String  | 是       | A192308 | 法规文件唯一标识ID |
| tiao     | String  | 是       | 5       | 法规条款编号       |
| pagenum  | Integer | 是       | 1       | 当前页码，从1开始  |
| pagesize | Integer | 是       | 10      | 每页返回数量       |

# 9. 分页说明

接口采用页码分页模式。

例如：

查询第1页，每页10条：

```
{
    "pagenum":1,
    "pagesize":10
}
```

返回：

```
total = 352
pagesize = 10
```

说明：

- 共352条数据
- 每页10条
- 总页数约36页

下一页：

```
{
    "pagenum":2,
    "pagesize":10
}
```

# 13. 开发注意事项

1. **gid和tiao必须同时传递**

仅传法规ID无法确定查询范围。

1. **tiao为字符串类型**

例如：

正确：

```
"tiao":"5"
```

不要：

```
"tiao":5
```

1. **分页从1开始**

不要传：

```
"pagenum":0
```

1. **total用于前端分页展示**

例如：

```
total=352
pagesize=10

总页数：
ceil(352/10)=36
```

1. **resultitem可能为空**

当法规条款没有关联期刊时：

```
{
 "resultitem":[]
}
```

属于正常业务返回。

# 14. 接口简要说明（用于接口目录）

| 项目     | 说明                           |
| -------- | ------------------------------ |
| 接口名称 | 法规条款引用期刊查询           |
| 请求方式 | POST                           |
| 接口路径 | /m/v6/api/jrflqk/getflqklink   |
| 输入     | 法规gid、条款号、分页参数      |
| 输出     | 引用该法规条款的期刊文章列表   |
| 主要用途 | 法规关联文献查询、知识关联展示 |

该接口本质上属于**法律知识图谱中的“法规条款 → 学术期刊”关联查询接口**，可作为法规知识关联、智能检索、AI法律问答中的引用扩展数据接口使用。
