# 国家法律正文详情接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

国家法律正文详情接口

### 1.2 接口地址

```
POST http://m-v2.faxin.cn/m/v6/api/fl/zyfl/content
```


## 1.3 功能介绍

该接口用于获取法信平台**国家法律法规库中文件正文详细信息**。

通过法律文件唯一标识 `gid` 查询对应法律法规的：

- 基础信息
- 制定机关
- 发布日期
- 发文字号
- 分类信息
- 效力状态
- 正文内容
- 历史版本信息

主要用于：

- 法律法规详情页展示
- AI法律检索后的正文获取
- 法律引用及关联分析
- 法律版本追踪

# 2. 请求说明

## 2.1 请求方式

| 参数         | 内容             |
| ------------ | ---------------- |
| HTTP方法     | POST             |
| Content-Type | application/json |
| 请求参数     | JSON             |
| 返回格式     | JSON             |

请求示例：

```
POST /m/v6/api/fl/zyfl/content

Content-Type: application/json
```

------

# 3. 请求参数说明

## 3.1 输入参数

| 参数名   | 类型   | 必填 | 默认值 | 说明                             |
| -------- | ------ | ---- | ------ | -------------------------------- |
| gid      | String | 是   | 无     | 法律文件唯一标识ID               |
| xsspflfg | String | 否   | 无     | 刑事审判法律法规项目详情访问标识 |

------

## 3.2 请求示例

普通法律详情查询：

```
{
    "gid":"A322145"
}
```

刑事审判法律法规项目调用：

```
{
    "gid":"A322145",
    "xsspflfg":"1"
}
```

------

# 4. 返回参数说明

## 4.1 返回结构

| 参数    | 类型    | 是否为空 | 说明         |
| ------- | ------- | -------- | ------------ |
| msg     | String  | 否       | 返回消息     |
| code    | String  | 否       | 返回状态码   |
| data    | Object  | 是       | 正文数据     |
| success | Boolean | 否       | 是否调用成功 |

------

## 4.2 状态码说明

| code | 含义     |
| ---- | -------- |
| 0    | 查询成功 |
| 其他 | 查询失败 |

------

# 5. 返回数据结构

接口返回：

```
{
    "data":{
        "fileinfo":{},
        "hisinfo":[],
        "isCanBrowse":"1"
    }
}
```

------

# 6. 文件基础信息 fileinfo

## 6.1 字段说明

| 字段       | 类型   | 说明         |
| ---------- | ------ | ------------ |
| gid        | String | 文件唯一标识 |
| title      | String | 文件标题     |
| fulltext   | String | 文件正文内容 |
| fwzh       | String | 发文字号     |
| fdate      | String | 公布日期     |
| ssrq       | String | 施行日期     |
| fdep_id    | Array  | 制定机关     |
| sort_id    | Array  | 主题分类     |
| shixiao_id | Array  | 时效状态     |
| xiaoli_id  | Array  | 效力等级     |

------

# 7. 字段详细说明

## 7.1 制定机关 fdep_id

数据格式：

```
[
    {
        "value":"国家能源局",
        "key":"009006003"
    }
]
```

字段：

| 字段  | 说明         |
| ----- | ------------ |
| key   | 制定机关编码 |
| value | 制定机关名称 |

示例：

```
"fdep_id":[
    {
        "value":"国家能源局",
        "key":"009006003"
    }
]
```

## 7.2 主题分类 sort_id

```

    {

]

字段：

| 字段  | 说明     |
| ----- | -------- |
| key   | 分类编码 |
| value | 分类名称 |

## 7.3 时效状态 shixiao_id

数据格式：

```

| 字段  | 说明     |

| 编码 | 含义             |
| ---- | ---------------- |
| 01   | 现行有效         |

# 12. 开发注意事项

## 12.1 gid处理

- `gid` 是法律文档唯一标识。
- 列表接口返回的 `gid` 可直接作为本接口查询参数。
- 建议业务系统保存 `gid`，避免使用标题作为唯一标识。

------

## 12.2 正文展示

正文内容字段：

```
fileinfo.fulltext
```

可能包含：

- 标题
- 发布机关
- 正文文本
- 发文字号

前端展示时建议进行格式化处理。

------

## 12.3 权限控制

展示正文前建议判断：

```
isCanBrowse == "1"
```

否则不要展示正文内容。

------

## 12.4 与搜索接口配合

推荐调用流程：

| 步骤 | 接口                 | 作用         |
| ---- | -------------------- | ------------ |
| 1    | 国家法律搜索列表接口 | 检索法律列表 |
| 2    | 获取gid              | 确定目标法律 |
| 3    | 国家法律正文接口     | 获取详细正文 |
