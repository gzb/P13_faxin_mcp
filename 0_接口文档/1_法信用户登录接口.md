# 法信用户登录接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

**用户账号登录接口**

### 1.2 接口用途

用于用户通过账号、密码方式进行身份认证。

登录成功后返回用户访问令牌（Token），后续访问需要身份认证的接口时，需携带该 Token。

主要应用场景：

- 法信移动端用户登录
- API接口身份认证
- 用户会话建立
- 用户信息获取

------

# 2. 接口信息

## 2.1 请求地址

```
http://m-v2.faxin.cn/m/v6/api/user/login
```

## 2.2 请求方式

```
POST
```

## 2.3 请求Content-Type

建议：

```
application/x-www-form-urlencoded
```

或：

```
application/json
```

（根据实际服务端实现选择）

------

# 3. 请求参数说明

## 3.1 请求参数

| 参数名   | 类型   | 必填 | 说明         | 示例    |
| -------- | ------ | ---- | ------------ | ------- |
| username | String | 是   | 用户登录账号 | appuser |
| password | String | 是   | 用户登录密码 | ******  |

## 3.2 请求示例

### POST请求

```
POST /m/v6/api/user/login HTTP/1.1

username=appuser
password=123456
```

JSON格式示例：

```
{
    "username":"appuser",
    "password":"123456"
}
```

------

# 4. 返回数据说明

## 4.1 返回结构

```
{
    "msg":"成功",
    "code":"0",
    "data":{},
    "success":true
}
```

------

# 5. 返回字段说明

## 5.1 顶层返回字段

| 字段    | 类型    | 说明                  |
| ------- | ------- | --------------------- |
| msg     | String  | 返回消息              |
| code    | String  | 返回状态码，0表示成功 |
| data    | Object  | 登录返回数据          |
| success | Boolean | 请求是否成功          |

------

# 6. data对象说明

返回示例：

```
{
    "loginType":"",
    "utype":true,
    "token":"xxxx",
    "name":"133*56001",
    "isExist":true
}
```

字段说明：

| 字段名    | 类型    | 是否必返回 | 说明                   |
| --------- | ------- | ---------- | ---------------------- |
| token     | String  | 是         | 用户登录认证Token      |
| name      | String  | 否         | 用户显示名称           |
| loginType | String  | 否         | 登录类型               |
| isExist   | Boolean | 否         | 登录账号是否存在       |
| utype     | Boolean | 否         | 用户绑定手机号逻辑标识 |

------

# 7. 字段详细说明

## 7.1 token

字段：

```
token
```

类型：

```
String
```

说明：

登录成功后生成的用户身份认证凭证。

示例：

```
eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1...
```

使用方式：

后续接口请求：

```
Authorization: Bearer {token}
```

或者：

```
token:{token}
```

（具体以接口规范为准）

------

## 7.2 name

字段：

```
name
```

类型：

```
String
```

说明：

用户显示名称。

示例：

```
133*56001
```

通常用于：

- 页面顶部用户名称显示
- 用户身份展示

------

## 7.3 loginType

字段：

```
loginType
```

类型：

```
String
```

说明：

用户登录类型。

可能值：

| 值     | 说明           |
| ------ | -------------- |
| mobile | 手机号登录     |
| uname  | 用户名登录     |
| 空     | 无特殊登录类型 |

示例：

```
{
    "loginType":"mobile"
}
```

------

## 7.4 isExist

字段：

```
isExist
```

类型：

```
Boolean
```

说明：

用于判断登录账号是否已经绑定。

取值：

| 值    | 说明         |
| ----- | ------------ |
| true  | 账号已经存在 |
| false | 账号不存在   |

与 `loginType` 配合判断：

例如：

```
{
    "loginType":"mobile",
    "isExist":false
}
```

表示：

> 手机号登录，但该手机号尚未绑定用户，需要执行绑定流程。

------

## 7.5 utype

字段：

```
utype
```

类型：

```
Boolean
```

说明：

用户绑定手机号流程控制字段。

业务规则：

### 场景1：

```
{
    "loginType":"mobile",
    "isExist":false,
    "utype":true
}
```

处理：

需要弹出手机号绑定页面。

流程：

```
用户登录
    |
    |
手机号账号
    |
    |
未绑定用户
    |
    |
弹窗绑定手机号
```

------

### 场景2：

```
{
    "utype":false
}
```

处理：

无需进入手机号绑定逻辑。

------

# 8. 登录流程说明

整体流程：

```
              用户输入账号密码
                      |
                      |
                      ↓
              调用登录接口
                      |
                      |
             username/password验证
                      |
        +-------------+-------------+
        |                           |
       成功                        失败
        |                           |
        ↓                           ↓
   返回token                    返回错误信息
        |
        |
        ↓
   判断登录类型
        |
        |
 +------+------+
 |             |
手机号        用户名
 |
 |
判断isExist
 |
 +-------------+
 |             |
存在          不存在
 |             |
正常登录       绑定手机号
```

# 10. 异常情况说明

## 10.1 登录失败

示例：

```
{
    "msg":"账号或密码错误",
    "code":"1001",
    "success":false
}
```

处理：

- 提示用户重新输入
- 不保存token

------

## 10.2 参数缺失

例如：

缺少username：

```
{
    "msg":"用户名不能为空",
    "code":"xxx"
}
```

处理：

客户端提交前校验。

------

# 11. 开发注意事项

## 11.1 Token管理

客户端：

- 登录成功保存token
- 请求接口携带token
- 登出后清理token

建议：

```
Token有效期内自动续期
```

避免频繁登录。

------

## 11.2 密码安全

建议：

- HTTPS传输
- 不记录明文密码日志
- 服务端完成密码加密校验

------

## 11.3 登录状态维护

推荐：

客户端保存：

```
{
    "token":"xxx",
    "username":"xxx",
    "loginTime":"xxx"
}
```

## 13. 后续接口关联说明

该接口为法信移动端API体系中的**认证入口接口**。

调用关系：

```
登录接口
    |
    |
    ↓
获取Token
    |
    |
    ↓
访问业务接口
    |
    +-- 法规查询
    |
    +-- 案例查询
    |
    +-- 用户权限
    |
    +-- 收藏记录
    |
    +-- 历史浏览
```

该接口返回的 `token` 是后续构建 **法信开放API、MCP服务、AI Agent工具调用认证体系** 的基础身份凭证。
