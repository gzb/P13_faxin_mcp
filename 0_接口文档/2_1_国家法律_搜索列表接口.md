# 国家法律搜索列表接口技术说明文档

## 1. 接口概述

### 1.1 接口名称

国家法律搜索列表接口

### 1.2 接口地址

```
POST http:///m-v2.faxin.cn/m/v6/api/fl/zyfl/searchdata
```

### 1.3 接口功能

该接口用于查询法信平台**国家法律法规库**中的法律文件列表。

支持：

- 法律分类查询
- 关键词检索
- 高级条件组合查询
- 按制定机关、效力等级、时效性等条件过滤
- 分页查询

适用于国家法律法规列表展示、法律检索等业务场景。

## 2.1 请求方式

| 项           | 内容             |
| ------------ | ---------------- |

| Content-Type | application/json |
| 请求参数格式 | JSON             |

# 3. 请求参数说明

## 3.1 基础查询参数

| 参数名         | 类型    | 必填 | 默认值 | 说明             |
| -------------- | ------- | ---- | ------ | ---------------- |
| libid          | String  | 否   |        | 法律库分类ID     |
| isadvsearch    | String  | 是   | 无     | 是否高级搜索     |
| pagesize       | Integer | 否   |        | 每页返回数量     |
| pagenum        | String  | 否   |        | 当前页码         |
| searchtype     | String  | 否   |        | 实际搜索类型     |
| usersearchtype | String  | 否   |        | 页面选择搜索类型 |

### libid分类说明

| libid      | 含义                 |
| ---------- | -------------------- |
| 不传       | 返回全部国家法律数据 |
| 010101_all | 法律                 |
| 010102_all | 立法解释             |
| 010103_all | 司法解释             |
| 010104_all | 行政法规             |
| 010105_all | 部门规章             |
| 其他       | 其他规范性文件       |

# 11. 开发注意事项

1. 分页处理
   - `pagenum` 从1开始。
   - `pagesize` 建议控制在10~50之间。
2. 分类查询
   - 如果查询全部法律数据，可以不传 `libid`。
   - 指定分类时使用对应 `libid`。
3. 高级搜索
   - 当使用多个过滤条件组合查询时，需要设置：

```
{
    "isadvsearch":"true"
}
```

1. 唯一标识
   - `gid` 为法律文档唯一ID。
   - 后续详情查询、收藏、关联引用建议使用 `gid`。
